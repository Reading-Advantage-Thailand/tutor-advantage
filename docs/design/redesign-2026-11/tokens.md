# Tokens: exact values per app, light and dark

Generated by `tools/gen-tokens-md.js` from one token source (`tools/tokens.js`), the live `apps/*/src/app/globals.css` files (read-only) and `tools/contrast.js`. Do not edit the tables by hand: change the source, re-run, re-check contrast. The tools live with the mocks (see README, "Files"); the paste-ready CSS in section 9 is the same data.

**How to apply (per app, one PR per app, plus one shared PR for the answer tiles):**

1. Replace the values inside the existing `:root { … }` and `.dark { … }` blocks of `src/app/globals.css` with section 9 for that app. Keep every token listed as "unchanged" below (layout, z-index, safe areas, legacy ramps).
2. Add the new `--color-*` mappings from section 7 to `@theme inline` and replace the `@theme` line-height block.
3. Point the shadcn tokens at the semantic tokens (section 5): no hex in the shadcn block any more.
4. In the same PR, sweep every `text-white` that sits on a brand fill to `text-on-brand` (README §5, item 4). Dark `--brand-solid` is light jade: white text on it is 1.99:1.
5. Run the contrast script and the `/dev/ui-kit` gallery in light and dark before any page migrates.

Token names: every name engineers use today is kept. New tokens are listed per app in section 3. Renamed or retired names keep working as aliases (section 4).

## Appendix: how the numbers are computed

- Contrast: WCAG 2.x relative luminance, `(L1 + 0.05) / (L2 + 0.05)`, sRGB channels linearised with the 0.03928 threshold. Translucent backgrounds are composited over the opaque surface they sit on (`under`), translucent foregrounds over the background.
- Colour difference: CIEDE2000 in CIELAB (D65).
- Colour-vision simulation: Machado, Oliveira & Fernandes (2009) matrices at severity 1.0, applied in linear RGB.
- Fonts: tabular figures measured by rendering "1111" and "0000" at 40px with and without `font-variant-numeric: tabular-nums` (Kodchasan 600/700: 60.5 vs 113.8 px, **no tabular figures**; Noto Sans Thai and Noto Sans Thai Looped: equal widths, tabular by default).
